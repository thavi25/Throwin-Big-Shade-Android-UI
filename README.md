# 🌞 TBS (Throwin Big Shade) Automatic Blinds Controller

## 🔍 Overview
TBS Automatic Blinds Controller is an Android application for controlling smart window blinds. This app provides a simple, intuitive interface to adjust settings for automated window covering systems.

## 📱 Features
- 🎛️ **Multiple Operating Modes**:
  - Automatic: Adjusts blinds based on environmental conditions
  - Blinds Up: Fully retracts the blinds
  - Semi-Permeable: Sets blinds to allow partial light through
  - Blackout: Fully deploys blinds to block all light

- 🌡️ **Temperature Control**:
  - Set temperature thresholds for automatic operation
  - Easy-to-use increment/decrement buttons
  - Current setting displayed in Fahrenheit

- 🌫️ **Opacity Percentage Control**:
  - Adjust the opacity level of the blinds
  - Simple +/- controls for fine adjustments
  - Visual display of current opacity setting
